# Local-Tourism-Experience-System
Full-stack MERN marketplace for authentic local tourism experiences in Nepal. Includes booking  logic, availability management, reviews, and real user traction (15+ hosts, 40+ bookings).
## Problem
Local tourism in Nepal is fragmented across WhatsApp and word-of-mouth. Tourists miss authentic experiences. Local hosts can't reach international travelers.

## Solution
A digital marketplace where local hosts create and sell experiences directly.
